# Conversation Coach

Copiloto silencioso para uma conversa de PDI: ouve a conversa (transcrição do navegador em pt-BR), identifica quem está falando e só orienta quando há algo útil a fazer.

Abra o link do GitHub Pages deste repositório no **Google Chrome do computador**. A página é gerada a partir do projeto `coach-app` (`npm run build:artifact -- --standalone`).

Nada é enviado para servidor: a transcrição e o relatório ficam no navegador de quem usa.
